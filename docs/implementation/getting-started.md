This guide begins when a country is ready to turn Digital Community System Toolkit decisions into specifications, configuration, integrations, deployment and operations.

| Starting from | Begin with |
|---|---|
| Policy and strategy | The DCS Toolkit |
| An existing product | Toolkit to validate users and governance, then this portal to plan adaptation |
| A defined roadmap | [Governance](./governance.md) |
| A deployed system | [Integrations](../integrations/index.md) and [Assurance](./assurance-testing.md) |
| Building a reusable reference | [Workflows](../workflows/index.md), [Standards](../standards/index.md) |
| Preparing for scale | [Go-live](./go-live-deployment.md) and [Operations](./operations-sustainability.md) |
