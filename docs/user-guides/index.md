Step-by-step guides to the applications in the [reference eCHIS](../architecture/index.mdx), one for each role. They describe current application behaviour, with screenshots from the reference environment, and are companion resources for [training](../implementation/training.md).

| Guide | Who it is for | Application |
|---|---|---|
| [CHW (VHT) app user guide](./vht-app/index.md) | Community health workers, called village health team members (VHTs) in the reference build | [eCHIS community health worker app](../architecture/components/echis-app.md) |
| [Supervisor app user guide](./supervisor-app.mdx) | Facility-based supervisors overseeing a team of VHTs | [Supervisor app](../architecture/components/supervisor-app.md) |
| [Administrator guide](./admin-portal.mdx) | Programme administrators who manage users, locations, teams and dashboards | [Web administration portal](../architecture/components/web-admin.md) |

The guides were last updated on 2 September 2026 and describe the reference environment at that date. Where a screen could not be verified, the guide says so. Country teams adapting the reference eCHIS should review the guides against their own configuration before issuing them.

For how each community health service works end to end, see [Workflows](../workflows/index.md).
